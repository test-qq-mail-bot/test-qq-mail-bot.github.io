# 网络拓扑图线路与布局展示规范

---

# 一、拓扑图展示目标

网络拓扑图用于直观展示设备之间的网络连接关系，以及设备连接所使用的端口信息。

拓扑图需要同时表达以下信息：

1. 设备之间的连接关系；
2. 设备所处的上下游层级；
3. 设备之间的物理线路方向；
4. 线路两端对应的源端口和目的端口；
5. 端口文字与线路之间的对应关系；
6. 不同空间排列方式下线路及端口文字的自适应展示。

其中，**端口文字属于线路的一部分，不作为独立悬浮文本处理**。

当拓扑图发生以下变化时：

- 设备移动；
- 线路长度变化；
- 拓扑布局重新计算；
- 画布缩放；
- 线路方向变化；
- 水平、垂直、斜向排列发生变化；

线路上的端口文字均应跟随对应线路同步变化。

---

# 二、拓扑图布局规则

## 2.1 两层拓扑架构

项目书中的网络拓扑采用两层结构进行展示：

- **汇聚层**
- **接入层**

不额外引入核心设备、上游网络、终端设备等独立层级。

基本结构为：

```text
汇聚层
   ↓
接入层
```

其中：

### 汇聚层

表示承担多个下级设备连接和汇聚功能的网络设备。

### 接入层

表示直接连接下级网络、终端或业务设备的网络设备。

---

## 2.2 两层布局原则

当拓扑关系能够明确区分上下游时：

- 汇聚设备位于上层；
- 接入设备位于下层；
- 同一层设备采用水平排列；
- 上下层之间通过连接线路关联；
- 线路从设备端口位置出发，连接至另一设备端口位置。

基本布局：

```text
┌──────────┐       ┌──────────┐
│ 汇聚设备1 │       │ 汇聚设备2 │
└─────┬────┘       └─────┬────┘
      │                   │
      ├─────────┬─────────┤
      │         │         │
┌─────▼────┐ ┌──▼──────┐ ┌▼────────┐
│ 接入设备1 │ │ 接入设备2 │ │ 接入设备3 │
└──────────┘ └─────────┘ └─────────┘
```

---

# 三、设备数量与空间分配

拓扑图根据设备数量自动调整空间分布。

| 设备数量 | 布局方式 |
|---|---|
| 1 台 | 画布中央 |
| 2 台 | 左右水平排列 |
| 3 台 | 左、中、右水平排列 |
| 4 台 | 四等分水平排列 |
| 5 台及以上 | 根据上下游关系进行分层布局 |
| 多设备 | 汇聚层在上、接入层在下，同层水平分布 |

当存在明确的上下游关系时，优先采用**上下两层布局**，避免所有设备强制处于同一水平线上。

---

# 四、拓扑线路统一规则

## 4.1 线路由三个视觉部分组成

每条设备连接线路统一按照以下结构理解：

**源设备端口 → 物理连接线路 → 目的设备端口**

例如：

```text
设备 A
   │
源端口
   │
══════════════
物理连接线路
══════════════
   │
目的端口
   │
设备 B
```

其中：

- 源端口文字必须靠近源设备；
- 目的端口文字必须靠近目的设备；
- 物理连接段用于表达实际线路；
- 端口文字必须嵌入线路视觉区域；
- 不允许把端口文字作为脱离线路的独立标签。

---

## 4.2 端口文字必须跟随线路

线路发生变化时，端口文字必须同步变化。

包括：

### 设备移动

设备 A 移动后：

> 线路跟随设备 A 重新连接，源端口文字同时跟随线路移动。

### 线路长度变化

两个设备之间距离发生变化：

> 线路长度发生变化，端口文字仍保持在线路对应位置。

### 拓扑方向变化

水平线路变成垂直线路：

> 端口文字由水平排列自动切换为垂直排列。

### 拓扑方向变化为斜向

水平或垂直线路变成斜向线路：

> 端口文字跟随线路方向进行斜向排列。

因此，端口文字不能采用固定画布坐标单独放置。

---

# 五、水平线路

## 5.1 适用场景

当两个设备处于同一水平层级，且设备之间主要沿 X 轴方向连接时，采用水平线路。

典型结构：

**设备 A → 源端口 → 物理线路 → 目的端口 → 设备 B**

---

## 5.2 水平线路文字规则

水平线路中的端口文字：

- 保持水平阅读方向；
- 与线路处于同一水平关系；
- 源端口位于源设备一侧；
- 目的端口位于目的设备一侧；
- 文字直接嵌入线路；
- 文字随线路整体移动；
- 线路长度变化时文字位置同步变化。

重点是：

> **不能把端口文字放在线路外部，再用一条线去连接文字。**

错误形式：

```text
设备 A

G1/0/1

──────────────

G1/0/2

设备 B
```

正确表达应体现为：

```text
设备 A ── G1/0/1 ───────── G1/0/2 ── 设备 B
```

其中端口文字与线路属于同一个线路视觉结构。

---

## 5.3 项目书拓扑图示例

水平线路采用 Mermaid 表达：

```mermaid
flowchart LR
    A["设备 A"] -->|"G1/0/1 ───────── G1/0/2"| B["设备 B"]
```

这里 Mermaid 只是**项目书中用于表达拓扑关系的示意方式**。

实际项目中的拓扑图并不要求使用 Mermaid 作为技术实现。

---

# 六、垂直线路

## 6.1 适用场景

当两个设备上下排列，线路主要沿 Y 轴方向连接时，采用垂直线路。

典型结构：

```text
设备 A
   │
   │
   G
   1
   /
   1
   │
   │
════════
物理连接
════════
   │
   G
   1
   /
   2
   │
   │
设备 B
```

---

## 6.2 垂直线路文字规则

垂直线路中的端口文字采用垂直排列。

例如端口：

`G1/0/1`

垂直展示为：

```text
G
1
/
0
/
1
```

端口文字本身必须处于线路对应区域，与线路保持统一的空间关系。

规则：

- 端口字符沿 Y 轴方向排列；
- 源端口位于源设备附近；
- 目的端口位于目的设备附近；
- 中间物理连接段不重复显示端口文字；
- 端口文字随垂直线路移动；
- 上下设备距离变化时，文字位置同步变化。

---

## 6.3 垂直线路示例

垂直线路采用 Text 形式描述：

```text
       设备 A
          │
          │
          G
          1
          /
          0
          /
          1
          │
          │
       物理连接
          │
          │
          G
          1
          /
          0
          /
          2
          │
          │
       设备 B
```

这里的 Text 仅用于**项目书中表达垂直线路的视觉效果**。

---

# 七、斜向线路

## 7.1 适用场景

当两个设备的 X、Y 坐标均存在明显差异时，采用斜向线路。

斜向线路需要同时解决：

- 线路方向；
- 端口文字方向；
- 文字与线路间距；
- 文字可读性；
- 线路移动后的同步变化。

---

## 7.2 斜向线路文字规则

端口文字必须跟随线路方向排列。

例如：

```text
设备 A
   \
    \
     G1/0/1
        \
         \
          ═════════
               \
                G1/0/2
                   \
                    \
                  设备 B
```

这里的关键不是让文字悬浮在线路旁边，而是：

> **端口文字必须属于斜向线路的视觉结构，并随着线路方向同步旋转或阶梯变化。**

---

## 7.3 斜向线路文字方向

斜向线路根据线路实际方向确定端口文字方向。

线路向右下方：

```text
G1/0/1
       \
        \
         \
          G1/0/2
```

线路向右上方：

```text
          G1/0/2
         /
        /
G1/0/1
```

文字不能固定保持水平后脱离线路。

---

## 7.4 斜向线路示例

斜向线路采用 Text 形式描述：

```text
设备 A
    \
     \
      G1/0/1
          \
           \
            ═════════
                   \
                    G1/0/2
                        \
                         \
                        设备 B
```

其中：

- `G1/0/1` 属于源端线路；
- `G1/0/2` 属于目的端线路；
- 中间线路表示物理连接；
- 所有文字位置均跟随线路变化。

---

# 八、三种线路的统一展示逻辑

三种线路虽然采用不同的文字排列方式，但遵循同一套核心规则。

| 线路类型 | 设备关系 | 端口文字方向 | 示例表达 |
|---|---|---|---|
| 水平线路 | 左右排列 | 水平 | Mermaid |
| 垂直线路 | 上下排列 | 垂直 | Text |
| 斜向线路 | 对角排列 | 沿线路方向 | Text |

---

## 8.1 水平线路

```text
设备 A ── G1/0/1 ───────── G1/0/2 ── 设备 B
```

端口文字与线路保持水平一致。

---

## 8.2 垂直线路

```text
设备 A
   │
   G
   1
   /
   0
   /
   1
   │
   │
   G
   1
   /
   0
   /
   2
   │
设备 B
```

端口文字沿线路垂直排列。

---

## 8.3 斜向线路

```text
设备 A
    \
     G1/0/1
          \
           \
            G1/0/2
                 \
                  \
                 设备 B
```

端口文字跟随线路方向。

---

# 九、线路与端口文字的位置关系

端口文字不是独立的拓扑节点。

线路展示时，应形成：

**设备 → 端口 → 物理连接 → 端口 → 设备**

而不是：

**设备 → 独立文字 → 线路 → 独立文字 → 设备**

---

## 9.1 源端口

源端口必须位于源设备连接线路的附近，并与线路保持连续的视觉关系。

例如：

```text
设备 A ── G1/0/1 ─────────────
```

---

## 9.2 目的端口

目的端口必须位于目的设备连接线路的附近。

例如：

```text
───────────── G1/0/2 ── 设备 B
```

---

## 9.3 物理连接段

两个端口之间的中间部分表示实际物理连接。

```text
设备 A ── G1/0/1 ═══════════ G1/0/2 ── 设备 B
```

物理连接段不重复显示端口名称。

---

# 十、线路动态变化规则

拓扑图发生变化时，线路和线路文字必须作为一个整体进行变化。

## 10.1 设备拖动

设备拖动后：

```text
设备位置变化
      ↓
线路重新连接
      ↓
端口文字同步移动
      ↓
重新判断水平 / 垂直 / 斜向排列
```

---

## 10.2 线路方向变化

例如：

```text
水平
设备 A ── G1/0/1 ───── G1/0/2 ── 设备 B
```

调整设备位置后变成：

```text
垂直

设备 A
   │
   G
   1
   /
   0
   /
   1
   │
   │
   G
   1
   /
   0
   /
   2
   │
设备 B
```

此时端口文字必须自动从水平排列切换为垂直排列。

---

## 10.3 斜向变化

当设备位置进一步发生变化：

```text
设备 A
    \
     G1/0/1
          \
           \
            G1/0/2
                 \
                  设备 B
```

端口文字同步进入斜向展示状态。

---

# 十一、线路模式判定

线路根据两个设备的空间位置确定展示方式。

设：

- `ΔX = X2 - X1`
- `ΔY = Y2 - Y1`

采用以下判断：

| 条件 | 线路模式 |
|---|---|
| `|ΔX|` 较小，`|ΔY|` 明显 | 垂直线路 |
| `|ΔY|` 较小，`|ΔX|` 明显 | 水平线路 |
| `|ΔX|` 与 `|ΔY|` 均明显 | 斜向线路 |

建议默认判断阈值为：

**20px**

阈值用于判断设备是否可以视为处于同一水平线或同一垂直线上。

---

# 十二、端口文字视觉规范

## 12.1 基础样式

| 属性 | 规范 |
|---|---|
| 字体 | 等宽字体优先 |
| 字号 | 12px |
| 文字颜色 | 深色 |
| 描边 | 白色描边 |
| 阴影 | 轻微白色阴影 |
| 可选中性 | 不允许 |
| 鼠标交互 | 不拦截线路及设备操作 |

---

## 12.2 文字可读性

无论线路处于：

- 水平；
- 垂直；
- 斜向；
- 放大；
- 缩小；

端口文字均必须保持清晰可识别。

尤其是斜向线路，文字不得因为旋转角度过大而出现倒置阅读问题。

---

# 十三、线路交叉与避让

当多个线路发生交叉时，应优先保证：

1. 设备之间的连接关系清晰；
2. 端口文字不相互覆盖；
3. 端口文字与其他线路尽量避免重叠；
4. 同一设备多条线路能够明确区分；
5. 不改变线路真实连接关系。

当端口文字可能与其他线路发生冲突时，可沿线路方向或线路法线方向进行适当调整，但调整后仍必须保持其属于原线路的视觉关系。

---

# 十四、拓扑图聚焦展示

当设备数量较多时，可以通过点击设备查看该设备的上下游关系。

聚焦某个设备后：

```text
        汇聚设备
           │
           │
        聚焦设备
           │
           │
        接入设备
```

仅保留：

- 当前聚焦设备；
- 与其直接连接的上游设备；
- 与其直接连接的下游设备；
- 当前设备与上下游设备之间的线路。

其他无关设备不参与当前聚焦视图展示。

---

# 十五、项目书拓扑图表达方式

项目书中的拓扑图需要根据线路方向选择合适的表达形式：

### 水平线路

使用 Mermaid 表达拓扑结构，例如：

```mermaid

    A["汇聚设备"] -->|"G1/0/1 ───────── G1/0/2"| B["接入设备"]
```

### 垂直线路

使用 Text 表达端口垂直排列效果：

```text
       汇聚设备
          │
          G
          1
          /
          0
          /
          1
          │
          │
          G
          1
          /
          0
          /
          2
          │
       接入设备
```

### 斜向线路

使用 Text 表达线路方向及端口跟随效果：

```text

                  \
                   \
                    G1/0/2

```

# 十六、最终统一原则

网络拓扑图的核心不是设备图标本身，而是：

> **设备、线路、端口三者形成一个完整的连接关系。**

因此必须遵循以下原则：

1. **端口文字属于线路视觉元素，不是独立标签。**
2. **端口文字必须内嵌在线路对应位置。**
3. **线路移动，端口文字同步移动。**
4. **线路缩放，端口文字同步缩放。**
5. **线路方向改变，端口文字排列方向同步改变。**
6. **水平线路采用水平文字。**
7. **垂直线路采用垂直文字，例如 `G / 1 / 0 / 1`。**
8. **斜向线路采用跟随线路方向的文字排列。**
9. **源端口和目的端口分别靠近对应设备。**
10. **物理连接段位于两个端口之间。**
11. **禁止将端口文字作为脱离线路的悬浮文字。**
12. **项目书中的 Mermaid、Text 仅用于描述和展示拓扑图效果，不代表实际项目的拓扑图技术实现方案。**

最终形成统一的线路视觉结构：

```text
源设备 ── 源端口 ═════════ 目的端口 ── 目的设备
```

并根据设备空间关系自动表现为：

**水平线路 → 水平端口文字**

**垂直线路 → 垂直端口文字**

**斜向线路 → 沿线路方向的端口文字**

这三种形式共同构成网络拓扑图的线路与端口展示规范。
