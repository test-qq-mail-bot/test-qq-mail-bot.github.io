预设 PRESETS ?按故障场景预置的 LogsQL 语句，点击一键填入并查询。支持 Ctrl+数字 快捷触发。
SYSLOG 级别 ?按严重等级(0最严重~7最轻)过滤。点某级别=只看它，再点取消。
设备 ?从查询结果自动提取的 hostname(按日志量排序)。点某设备=只看它的日志，下拉框可切换。
IP 过滤 ?手动输入任意 IP 回车即加入过滤，筛出含该 IP 的全部日志(精确匹配，不会误中 10.10.10.10)。可加多个，多个之间为"或"。与设备过滤并行生效。
尚未添加 IP
字段 ?从查询结果自动提取的结构化字段(如 hostname/severity/facility)。点某字段=只看含该字段的日志，并加载其取值。
查询后自动提取
字段值 ?上方所选字段在当前结果里的取值(按出现次数排序)。点某值=精确过滤，可多选叠加。
先选字段
收藏 ?把常用查询保存为收藏，下次一键调用。点名称应用，点右侧 x 删除。

- 统计柱子可点击下钻
